# Rehearsal

Weekly rehearsal over metalhead.link. Bob runs the click; Alice plays
guitar through a tempo-synced tremolo and a reverb, with a looper.

- `alice.txt`: Scarlett 2i2, guitar on input 1. `startup` is a dry-ish sound, `verse` adds the
  tremolo, `solo` opens the reverb.
- `bob.txt`: Scarlett 2i2, click on output 2 (the in-ear mix), drums mic on input 1 through
  Essentials' Compressor.
